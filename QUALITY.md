# Quality contract

This assistant serves faculty, administrators, and other campus professionals. Answers lead with the useful conclusion, cite the exact public record, distinguish proposed from adopted actions, and state a specific source limit without turning every exchange into a referral.

The interface uses one transcript and one composer. An active request cannot be submitted twice. Failed requests can be retried in place without duplicating the question or discarding a new draft. Refresh preserves the current visit in tab-scoped session storage; New conversation clears it. No transcript is saved to the server. Email links open an unsent draft containing the original question for the active topic.

Normal chat startup requires only the small snapshot manifest and backend health check. The full search index and source inventory load on demand. Source search remains available if the AI is unavailable, with the same transcript and composer. Source failures never leave a blank screen or erase earlier exchanges.

Retrieval preserves the active topic through short workflow follow-ups and long conversations. Specific identifiers use the bill index; general questions about legislation use the normal corpus. Search and procedural enrichment use cached indexes and bounded query terms rather than scanning every passage repeatedly.

Verification covers grounded curriculum, Kuali, Senate, tracker and bill questions; ambiguous and missing records; historical and conflicting dates; long conversations; malformed output; gateway and source failures; request limits; HTML/URL injection; keyboard navigation; source disclosure; narrow portrait and landscape layouts; and draft preservation during slow requests. Model responses receive a smaller, budgeted live evaluation in addition to the extensive deterministic suite.
